# NUMBERS Open in Edge Privacy Policy

**Effective date:** September 18, 2026  
**Developer:** James Campbell, LLC

## Purpose

NUMBERS Open in Edge provides a user-initiated command for opening an explicitly selected, linked, or copied HTTP or HTTPS address in Microsoft Edge. The extension requires the separately installed NUMBERS Windows launcher.

## Data processed

The extension may process the following website content only when the user expressly invokes one of its context-menu commands:

- A hyperlink that the user right-clicks;
- Text that the user selects as a web address; or
- A copied web address read locally by the NUMBERS Windows launcher after the user selects **Open copied URL in Microsoft Edge**.

The address is used only to perform the requested opening action. The extension and launcher reject addresses that do not use the HTTP or HTTPS protocol.

## Collection, storage, and disclosure

James Campbell, LLC does not collect, retain, log, sell, or disclose the processed address. The extension does not transmit the address to the developer, an analytics provider, an advertising service, or any other external service.

Processing occurs locally between the browser extension, the NUMBERS Windows launcher, and Microsoft Edge. No developer-operated server is used.

## Other browser information

The extension does not access or collect passwords, authentication credentials, cookies, browsing history, financial information, personal communications, health information, location information, or keystroke and mouse activity.

## Data retention

The extension and launcher do not retain the processed address after the requested action is completed.

## Limited use

Any website content processed by the extension is used solely to provide its single user-facing function. It is not used for advertising, profiling, creditworthiness, lending, or any unrelated purpose.

## Changes

This policy may be updated if the extension's functionality or data practices change. The effective date above identifies the current version.
